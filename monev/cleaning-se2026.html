Cara menghitung

Kapan tugas dihitung "sudah dilakukan"?

Setiap baris di sheet Verif adalah satu tugas untuk pegawai di kolom Nama Organik yang Ditugaskan. Baris tanpa nama pegawai masuk ke (Belum ditugaskan).

Nama pegawai ditulis berbeda-beda di tiap sheet

Nama panggilan disamakan otomatis dengan nama lengkap bergelar yang ada di spreadsheet, misalnya Tiara → Tiara Ariradana, A.Md.Stat. atau Nugroho Dwi P → Nugroho Dwi Prasetio, SST. Ejaan yang berbeda (mis. Fadila, Fani, Okti) diatur di monev/config.js bagian alias.

Dari mana datanya, dan apakah aman?

Server PINTU (Apps Script Gmail kantor) membaca spreadsheet tindak lanjut Kab/Kota lalu hanya mengirim jumlah tugas per pegawai. Nama responden, NIK, alamat, dan link assignment tidak pernah dikirim ke browser. Hasil disimpan sementara 10 menit; tombol Perbarui data (pengelola/admin) mengambil ulang saat itu juga.

Pakai file Excel membaca file di perangkat Anda sendiri. File tidak diunggah ke mana pun.
